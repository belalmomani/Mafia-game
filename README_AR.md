# لعبة المافيا (Android + Supabase) — المشروع الكامل

> أُنشئ هذا المشروع من الهاتف ولم يُبنَ ولم يُشغَّل على جهاز فعلي من طرفي. أول بناء على GitHub وتشغيل اختبارات SQL هما الاختبار الحقيقي؛ أرسل لي أي خطأ كما هو.

## المحتوى
```
app/                      تطبيق Android (Kotlin + Jetpack Compose، واجهة عربية RTL)
  src/main/res/drawable-nodpi/card_*.png   صور الأوراق (مقصوصة من الصورة التي أرسلتها)
supabase/
  migrations/0001..0011   قاعدة البيانات (شغّلها بالترتيب)
  verify/verify_setup.sql فحص سريع
  tests/                  اختبارات الصلاحيات والأدوار
  seed/                   بيانات وهمية (اختياري)
supabase.properties       رابط المشروع والمفتاح العام (عدّله هنا لاحقًا)
.github/workflows/android.yml   بناء APK على GitHub
SUPABASE_SETUP_AR.md      شرح مفصل لإعداد Supabase من الهاتف
RULES_AR.md               قواعد اللعبة والأدوار والتوزيع
```

## 1) قاعدة البيانات
في SQL Editor، **كل ملف وحده وبالترتيب**: `0001` … `0012`، ثم **`0013` (وحده)** ثم `0014` ثم `0015`، ثم **`0016` (وحده)** ثم `0017` ثم `0018` ثم `0019` ثم `0020`.
بعدها: `verify_setup.sql` (كل الصفوف OK) ثم `tests/001` و`002` و`003` (صفر FAIL).
> إن نفّذت حتى 0018 فالجديد فقط: **0019 ثم 0020**. **لا تُعد تشغيل 0014 بعد 0017 أبدًا**؛ إن احتجت إعادة شيء فأعد 0017 ثم 0018 ثم 0019 ثم 0020 بالترتيب.

## 2) تفعيل الدخول المجهول
Supabase ← Authentication ← Sign In / Providers ← **Allow anonymous sign-ins**.

## 3) بناء التطبيق من الهاتف
1. ارفع كل محتويات المشروع إلى مستودع GitHub (فرع `main`) بنفس المسارات.
2. Actions ← **Android Debug Build** ← Run workflow.
3. نزّل `mafia-debug-apk`، فكّ الضغط، ثبّت `app-debug.apk` فوق القديم.
4. لتغيير الرابط/المفتاح: عدّل `supabase.properties` وأعد البناء. **ممنوع** وضع `service_role` أو Secret key.

## 4) كيف تختبر لعبة كاملة
تحتاج 4 لاعبين على الأقل (4 هواتف، أو هاتف + أجهزة أصدقاء). كل جهاز يدخل مجهولًا تلقائيًا.
1. كل لاعب يكتب اسمه ويحفظه.
2. أحدهم ينشئ غرفة (خاصة) ويشارك الرمز، والبقية ينضمون.
3. المالك يفعّل «جولات سريعة» (20 ثانية) ثم **ابدأ اللعبة**.
4. تبدأ اللعبة بالتبرير (دور لكل لاعب). تظهر ورقة الدور لكل لاعب. الليل: المافيا/الأحمر يختارون الضحية، والبنت تحمي، والشيخ يفجّر. النهار: الصياد يطلق (اختياري). التصويت: صوت واحد لا يتغير.
5. تنتقل المراحل تلقائيًا بانتهاء الوقت، أو مبكرًا عند اكتمال إجراءات الليل / أصوات الجميع.

## الدورة الجديدة
راجع `RULES_AR.md` للقواعد الكاملة: التبرير بدور لكل لاعب، التصويت، خروج المافيا يعيد التبرير، الليل، «اغتيال فاشل»، ومافيا الإسكات الاختياري.

## الإعلانات (Start.io)
بانر صغير أسفل الشاشة خارج المحتوى فلا يغطي شيئًا (معرّف التطبيق 209829027 في `AndroidManifest.xml`). نسخ debug تطلب إعلانات تجريبية. **لا تضغط على إعلاناتك الحقيقية**. حدّث سياسة الخصوصية ونموذج بيانات Google Play عند النشر، وراجع إعدادات الموافقة (GDPR) في لوحة Start.io.

## الميزات الأخيرة
دردشة اللعبة (المتحدث نهارًا، والمافيا ليلًا) · رابط غرفة صوتية خارجية · بوتات للتجربة · تخطي الغائبين والانسحاب · الولد يختار لحظة موته · إدارة الغرفة (طرد، مشرفون، دعوات باسم المستخدم) · بلاغات · ربط الحساب بالبريد · تحديث لحظي (Realtime) · اهتزاز وإشعارات محلية · منع لقطة الشاشة على ورقة الدور · شاشة القواعد · بناء release موقّع. التفاصيل في `RULES_AR.md` و`docs/RELEASE_AR.md`.

## الميزات الأحدث
إحصاءات اللاعبين والترتيب · صور رمزية · لوحة إدارة البلاغات (`docs/ADMIN_AR.md`) · تسجيل Google اختياري (`docs/GOOGLE_SIGNIN_AR.md`) · تنظيف دوري للألعاب القديمة (pg_cron إن فُعّل).

## ما تم (المراحل 4–6)
- **4:** بدء اللعبة، الانتقال التلقائي لكل أعضاء الغرفة، كشف الدور بورقته، العودة لغرفتك بعد الإغلاق.
- **5:** واجهة الليل لكل دور، اقتراحات المافيا السرية، هدف سحب الولد.
- **6:** النهار (الصياد)، التصويت مع تأكيد، سجل الأحداث، سجل التصويت التفصيلي (للمالك أو للجميع حسب إعداد الغرفة)، شاشة الفوز مع كشف الأدوار، إلغاء اللعبة للمالك.

## حدود معروفة (للمراحل القادمة)
- التحديث اللحظي (Realtime) يعمل كمسرّع فوق استطلاع احتياطي كل 3 ثوانٍ.
- الإشعارات محلية فقط (تعمل ما دام التطبيق حيًا في الخلفية)؛ الإشعارات الفورية الكاملة تحتاج Firebase (FCM).
- تسجيل Google جاهز لكنه يحتاج إعداد OAuth (مخفي حتى تضع المعرّف).
- لم تُضف بعد: إشعارات FCM الفورية، والصوت المدمج.
- الجلسة المجهولة تضيع عند مسح بيانات التطبيق (نضيف بريدًا/Google لاحقًا).
- لا طرد/مشرفين/دعوات/بلاغات من الواجهة بعد (الدوال جاهزة في الخادم).
- حد الغرفة 20 لاعبًا، والجولات لا تتعامل مع لاعب يغادر التطبيق (يمضي الوقت وتستمر اللعبة).
- صور الأوراق دقتها ~300 بكسل؛ لو لديك كل ورقة منفصلة بدقة أعلى أرسلها لاستبدالها.
