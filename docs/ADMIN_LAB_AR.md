# صفحة المشرف ومختبر التجربة

البريد المخصص للمشرف: `bilalalmomani90@gmail.com`

## 1) تفعيل صلاحيتك (مرة واحدة)
> **مهم أمنيًا:** قبل البدء تأكد من تفعيل **Confirm email** في Supabase (Authentication ← Sign In / Providers ← Email). الصلاحية تُمنح فقط لحساب بريده **مؤكَّد**، ولأول من يطالب بها، ثم تُغلق.

1. في التطبيق: «حسابي» ← اكتب بريدك وكلمة مرور (6 أحرف فأكثر) ← **ربط حسابي الحالي بهذا البريد**.
2. افتح رسالة التأكيد في بريدك واضغط الرابط.
3. ارجع للتطبيق ← «حسابي» ← **🛡️ تفعيل صلاحية المشرف**.
4. من الشاشة الرئيسية يظهر **🛡️ لوحة الإدارة**.

(بديل بلا بريد: أضف معرّف حسابك يدويًا حسب `docs/ADMIN_AR.md`.)

## 2) مختبر التجربة
لوحة الإدارة ← **🧪 مختبر التجربة**:
1. اختر عدد اللاعبين (4 افتراضيًا) و«مؤقتات قصيرة» ثم **ابدأ لعبة تجريبية**.
2. ترى **كل الأدوار** والإجراءات والرسائل وكل الأحداث (حتى السرية).
3. اضغط **تحكّم** على أي لاعب وهمي ونفّذ إجراءاته: اغتيال/حماية/تفجير/إسكات ليلًا، إنهاء دوره في الكلام وإرسال رسالة، التصويت، طلقة الصياد، اختيار الولد، الانسحاب.
4. **⏩ التالي الآن** يتجاوز المؤقت. **🎲 عشوائي للباقين** يجعل من لم يتصرف يتصرف عشوائيًا.
5. **🗑️ حذف المختبر** يحذف الغرفة والحسابات الوهمية.

### ضمانات
- كل إجراء يمر عبر **نفس دوال اللعبة الحقيقية**، فتُطبَّق كل القواعد (من لا يحق له الإجراء يُرفض).
- عرض الأدوار الكاملة متاح **لألعاب المختبر فقط**، ولا يكشف أدوار الألعاب الحقيقية.
- كل دوال المختبر ترفض غير المشرف على الخادم.
