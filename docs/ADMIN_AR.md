# لوحة إدارة البلاغات

1. افتح التطبيق ← «حسابي» ← انسخ **معرّف حسابك**.
2. في Supabase SQL Editor شغّل (بعد وضع معرّفك):
```sql
insert into public.app_admins (user_id) values ('ضع-معرّفك-هنا');
```
3. أعد فتح التطبيق: يظهر زر «🛡️ لوحة الإدارة (البلاغات)» في الشاشة الرئيسية. تعرض البلاغات المفتوحة وتغيّر حالتها (مراجعة / تم الحل / رفض).

الصلاحية محمية في الخادم: جدول المشرفين مغلق على العميل، ودوال الإدارة ترفض غير المشرفين.
